# v1.2.2 未发布开发草稿

> 历史状态：此文件是在 v1.2.1 发布后形成的本地开发草稿。实际 Git 历史和 GitHub 均没有 v1.2.2 tag 或 Release；其中实现经重新审查后并入唯一获授权的 v1.3.0。本文件仅保留开发时间线，不能作为发布、测试或当前产品行为的证明。

v1.2.2 是 v1.2.1 的纠正版。它修复全新主机在十项向导完成后、首次 Compose 候选校验阶段因 Provider/Crisp 后置字段尚未落盘而中断的问题；`staged` 部署现在能保留全部配置和内部秘密继续启动。已有实例的 `--reconfigure --skip-start` 会在发生配置或运行态变更前拒绝，受管 Caddy 候选失败也不会提前提交新的 Provider 配置。

客服运行时同时加固两个边界：人工期间产生、恢复后才迟到投递的旧访客消息不会被当成新问题补答；Provider 配置事务期间，固定回复、人工确认和本地菜单仍立即工作，只有真正需要知识或模型的任务才持久等待。v1.2.1 的评价邀请停用、1 主 20 备、中文界面、中性客服显示、人工即时暂停、知识补召回和有界发送对账均保持。

本版还修复固定 n8n Code runner 被慢推理占满时的新消息接收延迟。生产并发固定为 10，后台处理最多使用 8 个执行许可，其中普通长任务最多 7 个；拿不到许可的任务立即回到持久队列并短延后，始终为 Webhook 接收等轻量入口保留 2 个 runner。受控固定镜像中，修复前第 11 个 Hook 等待约 11.84 秒；修复后普通任务满载时，新 Hook 约 0.18 秒完成持久接收。该证据属于本地生产工作流压力测试，不冒充 Crisp 公网投递时延。

Website Hook 继续作为实时入口；针对 Website 模式没有同等失败重试保证的边界，本版增加当前站点的有界 REST 补偿。第一次运行只建立当前水位，不回复历史会话；此后按短时间窗和有限请求补回漏投的访客消息或真人公开回复，并继续使用同一套去重、单会话人工状态、总开关和发送前复核。补偿查询与已有本地任务并行，Crisp REST 超时不会拖住已持久消息。

访客可见输出也增加最后一道统一收敛：上游返回纯机械故障话术、全部接口失败、执行中断或升级遗留待发计划时，只发送一条与当前输入相关的自然澄清；不会把 Provider 名称、内部错误、自动化身份或“稍后重试”字样交给访客。正常业务事实、安全拒答、用户 Prompt 和知识原文保持原样。

## 唯一推荐安装命令

在 Debian 12/13 或 Ubuntu 22.04/24.04 的交互终端执行这一整行。它匿名读取公开 `get.sh`，锁定 Latest 的具体 tag，下载并校验同版完整包，然后进入十项初始化：

<!-- CRISPAI_RECOMMENDED_INSTALL_COMMAND -->
```bash
bash -c 'set -euo pipefail; u=https://raw.githubusercontent.com/statusX7/ai-support/main/get.sh; t=$(mktemp /tmp/crispai-get.XXXXXXXX); cleanup(){ r=$?; trap - EXIT; rm -f -- "$t"; exit "$r"; }; trap cleanup EXIT; f=; if [[ -s /etc/ssl/certs/ca-certificates.crt ]] && command -v curl >/dev/null 2>&1; then f=curl; elif [[ -s /etc/ssl/certs/ca-certificates.crt ]] && command -v wget >/dev/null 2>&1; then f=wget; else command -v apt-get >/dev/null 2>&1 || { printf "错误：当前系统无法自动安装安全下载工具。\n" >&2; exit 1; }; p=(); if (( EUID != 0 )); then command -v sudo >/dev/null 2>&1 || { printf "错误：需要 root 或 sudo 补齐安全下载工具。\n" >&2; exit 1; }; p=(sudo --); fi; "${p[@]}" env DEBIAN_FRONTEND=noninteractive apt-get -q -o APT::Color=0 -o Dpkg::Use-Pty=0 -o DPkg::Lock::Timeout=180 -o Acquire::Retries=3 -o Acquire::http::Timeout=30 -o Acquire::https::Timeout=30 update; "${p[@]}" env DEBIAN_FRONTEND=noninteractive apt-get -q -o APT::Color=0 -o Dpkg::Use-Pty=0 -o DPkg::Lock::Timeout=180 -o Acquire::Retries=3 -o Acquire::http::Timeout=30 -o Acquire::https::Timeout=30 install --yes --no-install-recommends ca-certificates curl; f=curl; fi; if [[ "$f" == curl ]]; then curl -q --fail --location --silent --show-error --max-redirs 5 --proto "=https" --proto-redir "=https" --tlsv1.2 --retry 3 --retry-delay 2 --connect-timeout 15 --max-time 300 --output "$t" "$u"; else wget --no-config --no-netrc --https-only --secure-protocol=TLSv1_2 --timeout=30 --tries=3 --output-document="$t" "$u"; fi; e=; while IFS= read -r l || [[ -n "$l" ]]; do e=$l; done < "$t"; [[ -s "$t" && "$e" == "# crispai-get-end" ]] && bash -n "$t" || { printf "错误：get.sh 下载不完整或语法无效。\n" >&2; exit 1; }; chmod 0700 "$t"; bash "$t"'
```

安装完成后使用：

```bash
crispai
crispai status
crispai doctor
```

已有 v1.2.1 实例从 `crispai → 14 → 1` 匿名检查并更新；不要覆盖 v1.2.1 tag 或手工搬运个别脚本。此前停在 `installing`/`staged` 的实例可重新执行同一在线命令，程序会严格校验并复用保存的十项配置。

## 验收边界

正式发布前，完整冻结包必须先通过本地全量回归、真实 Debian 12 空机安装恢复和 TARGET-A 同包验收；发布后再做无 GitHub 登录的匿名下载与新手命令实装。最终 Release、资产 SHA、匿名结果和目标机正式内容核对以同 Release 的独立 `v1.2.2-verification.md` 为准，本页不预填尚未发生的远端结果。

跨 GitHub、Provider、Crisp 与访客网络无法承诺绝对送达。程序提供持久接收、有序故障切换、发送前状态复核及有限回执对账；明确的账户拒绝、所有上游不可用或平台长期无法确认回执时会留下可诊断故障，而不会谎报成功或无限重复回复。
