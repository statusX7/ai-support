# v1.3.3 发布说明

修复添加 OhMyGPT 备用接口时的输出参数不兼容。GPT 接口明确要求 `max_completion_tokens` 时，程序保留原输出额度调整字段；如同时拒绝温度，再使用接口默认温度。每项只调整一次，所有尝试共享原请求的剩余时间，不改变正常模型的参数。

参数错误现在明确显示为“接口拒绝请求参数”，不再统一提示地址或响应协议不符。不会因此绕过鉴权、安全拒绝、响应完整性或人工接管；全池失败仍记录真实失败，不发送空泛话术冒充成功。

OhMyGPT 可填写 `https://api.ohmygpt.com` 或其 `/v1` 基址，使用模型列表中的准确 ID；本次问题的测试模型为 `gpt-5.6-sol`、`claude-sonnet-4-6` 和 `deepseek-v4-flash`，使用 Chat Completions。上下文窗口按实际接口能力配置，不强制统一上限。

[修复报告](../reports/v1.3.3-report.md)说明已复现根因及修改边界；同一 Release 的核验附件记录冻结包实际运行、三模型知识问答和送达结果。未改变的安装流程复用 v1.3.2 同实现证据，不重复空机矩阵。历史版本不覆盖。
