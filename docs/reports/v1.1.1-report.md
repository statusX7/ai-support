## 4. 在线入口与新手流程

唯一推荐命令以 [INSTALL.md](../INSTALL.md) 顶部代码块为准，与 README 和本版 Release notes 逐字一致，并由自动测试核对。命令先检查 curl/CA，必要时利用已有 wget 或受控 apt 补齐；下载至随机受限文件，检查完整结束标记及 Bash 语法后执行并保留退出码。

get.sh 不预先读取邻接模块。默认只解析一次具体稳定 tag，核对正式 Release 元数据，再固定下载归档与单目标 SHA256SUMS；拒绝 HTML、路径穿越、重复成员、链接/特殊文件、超限内容及版本混用。校验清单是同源完整性证据，不是独立发布者签名。

同版本默认进入管理菜单；旧版不静默升级；`--update` 使用目标包的维护逻辑；中断与安全卸载复用持久资料；非项目非空目录拒绝写入。无交互终端非零退出。普通用户通过受控 sudo 进入，不传递失效 stdin FD。

快速初始化依旧是 API 地址、隐藏 Key、模型、Website ID、隐藏 Identifier、隐藏 Crisp Key、公网地址、Prompt、知识、数字确认共十个主步骤。文件路径的正常输入为 10 项，确认后不得新增内部参数提问。Prompt/多库扩展输入不伪称十次按键。

## 5. 自检语义

菜单 2：快速、完整、缓存结果、安全修复、脱敏导出。`crispai doctor` 默认不推理、不修复；`--local` 不发外部业务请求；`--full` 显式授权少量合成推理；`--json` stdout 只含 JSON；`--fix` 只执行白名单后复检。总预算默认 90 秒，单项卡住仍汇报其余检查。

结果逐项包含 id、中文名称、状态/严重性、摘要、时间、耗时、来源/范围、修复建议。退出码 0/2/1 分别为无问题、警告待接入、明确故障；64 参数错误、130 中断。安装/回滚的兼容健康入口将非关键外部待接入与必要组件故障分开处理。

检查不发送客户消息、不刷新全部知识索引、不调整总开关或人工/offer/截止时间。scheduler 心跳由现有定期扫描主动维护，而不是借客户流量判断；默认 doctor 只读它。失败恢复或未完成安装状态不允许 fix 擅自启动混合代际服务。
