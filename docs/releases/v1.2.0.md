## 已安装实例

运行 `crispai`，进入 `14 → 1` 匿名在线更新；升级前自动快照，失败按实际状态回滚。仅入口缺失时使用高级手册的同版本 `get.sh --repair`，不是重新填写全部参数。正式命令保持 `crispai`；无冲突时同时提供受管 `crisp` 兼容入口。

## 资料与维护

- 原 Prompt、知识和业务配置继续保存在实际部署目录，不搬入下载目录或临时管理员 HOME。直接编辑后先 `crispai apply --check`，再 `crispai apply`；需要重新同步组件时显式 `crispai apply --force-external`。半写入、非法内容或同步失败不假报生效。
- 菜单 `15` 提供限量日志、可中断跟随、数字确认轮转/清理、保留策略及脱敏导出。文件按天、Docker 按容量、n8n execution 按应用策略分别管理；不清会话、知识、任务、Docker 私有日志文件或系统审计日志。
- `crispai doctor` 默认只读，新增资料未应用与日志调度核验；`--full` 和 `--fix` 分别用于明确授权的少量推理检查和受管安全修复。
- 升级、完整备份、业务导出、回滚与数字卸载包含新增受管模块及资料；保留旧合法设置，不重置人工状态。
