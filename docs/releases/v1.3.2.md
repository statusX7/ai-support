# v1.3.2 发布说明

本版针对重装后安装失败、续装不能修改输入及残留配置互锁。可以从未完成安装选择最新正式修复版，再保留或修改已填数据；取消不会清空正式配置。上下文窗口按中转实际能力输入，修复完整接口池与知识预算链路，不截断 Prompt、不跳过 Caddy 或容量校验。

已具备管理条件但最终检查失败时仍保留 crispai 入口，可用菜单 1 续装、菜单 3 修复接口、doctor 查看真实故障；入口存在不等于 ready。内部 Key、已有知识及人工保护继续保留，未完成咨询不通过清空记录消除告警。

项目目标是持续维护 ai-support，当前授权交付 v1.3.2；v1.3.1 及历史发布不变。采用受影响增量验收，不因版本号重跑无关旧矩阵。必须完成目标机实际续装、干净 VM 的失败再编辑恢复、真实业务及同包检查才可正式发布；最终事实及摘要见同一 Release 的独立核验附件。[修复报告](../reports/v1.3.2-report.md)
