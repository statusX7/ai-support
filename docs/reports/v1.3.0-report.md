# CrispAI v1.3.0 交付报告

> 本报告当前处于执行阶段，只记录已经发生且可公开的非敏感事实。TARGET-A 的身份、业务配置、Prompt、知识、客户消息和原始日志只保存在受限现场。正式 Release、资产 SHA、匿名回下载与目标机最终同包结果由发布后的独立 `v1.3.0-verification.md` 记录。

## 1. 基线与版本政策

- 公开基线：v1.2.1，tag commit `4b923d60233f48a37d545d3f345200cfa8161266`；远端 Latest 在本轮开始时仍为 v1.2.1。
- 开发起点：`4139e4b69440c33cef8e3fb088426253addb0f07`，工作树包含未提交的 v1.2.2 开发素材。
- 本轮唯一目标：v1.3.0。`config/release-policy.json` 明确禁止自动递增、只允许一个 v1.3.0 新 Release，并要求 TARGET-A 同包验收。
- 发布入口、打包入口和源码门禁均校验该政策；正式结果尚未发生，不在本报告预填。

## 2. v1.2.2 时间线复盘

已核对的事实：v1.2.1 于 2026-09-14 正式发布；之后本地未提交工作树把 VERSION 与 AGENTS 目标改为 v1.2.2，并记录了干净安装 Compose 候选校验、runner 饱和、REST 补偿等技术修复。Git 中没有 v1.2.2 commit/tag，GitHub 没有 v1.2.2 Release。当前可见记录未找到用户授权切换产品版本的证据。

因此，技术上继续修复公开包新发现的缺陷具有明确动机，但“发现缺陷”不等于“获准创建新产品版本”。本轮将未提交实现作为待审查素材纳入 v1.3.0，而不是发布或改写历史。

## 3. 执行与证据边界

- 开发断点规范见 `docs/PROJECT-WORKFLOW.md`；私密状态位于被 Git 忽略的 `.work/v1.3.0/control/`。
- 所有产品静态、契约、固定组件、归档和真实业务测试只在 TARGET-A 执行；开发机结果不计入本轮通过数。
- P0 根因、空间清理、TARGET-A 同包身份、测试计数及外部边界将在取得对应证据后补齐。
