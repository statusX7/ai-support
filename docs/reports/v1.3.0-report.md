## 2. v1.2.2 时间线复盘

因此，技术上继续修复公开包新发现的缺陷具有明确动机，但“发现缺陷”不等于“获准创建新产品版本”。本轮将未提交实现作为待审查素材纳入 v1.3.0，而不是发布或改写历史。
