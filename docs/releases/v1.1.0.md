# v1.1.0：Shell 管理与客服功能收尾

本版本将日常维护集中到受管的 `crispai` 命令：18 项中文 Emoji 菜单、Prompt 多行粘贴、命名知识库、第三方 API/模型与 Chat/Responses 接线、关键词按钮、欢迎、总开关和单会话恢复。

人工规则发生明确变化：输入人工关键词只显示原生选择卡片，点击确认才暂停自己的 AI；真人公开回复则立即暂停该会话。其他会话继续服务，0 秒表示不自动恢复。旧词表和合法自定义设置保留，旧直接 handoff 动作迁移为按钮确认。

继续保留十项快速初始化、自动依赖与 Docker/应用初始化、图片/上下文、知识索引、业务迁移、本机敏感备份、升级回滚和数字确认卸载。业务导出含全部库原文但不含秘密；完整本机备份含恢复需要的秘密，不应公开分享。

## 获取与运行

仓库保持 private，需已有访问授权。下载本 Release 的完整源码包及 `SHA256SUMS`，上传到目标服务器：

```bash
sha256sum --check SHA256SUMS
tar -xzf ai-support-v1.1.0.tar.gz
cd ai-support-v1.1.0
sudo bash ./install.sh
crispai
```

root 可直接 `bash ./install.sh`。目标机从归档安装不需要 Git/gh 或宿主 Node/npm；依赖由支持系统上的安装器补齐。默认 `/opt/crisp-ai`，保留 `--deploy-dir`。

## 外部验收边界

本地真实 Docker、n8n、AnythingLLM 和向量索引的证据与受控 Crisp/Provider 协议测试分层报告；协议服务不是实际大模型或真实 Crisp Web Chat。尚未取得的真实 Crisp、第三方模型、公网 DNS/TLS 与站点修改权限标记为 `External Validation Pending`。源码发布不能代替使用者的账号授权及 Hook 后台登记。

升级后检查 Website Hook 新增订阅 `message:updated`；默认文本接入仍使用单一 Website Token/Website Hook。可选网页加载/打开欢迎需一次性无密钥 SDK 片段和 `session:sync:events`，不要求 Marketplace Plugin。
