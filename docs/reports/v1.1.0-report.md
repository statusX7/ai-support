## 4. 安装与配置的实际调用链

`install.sh` 参数/帮助 → bootstrap root/发行版 → 最小工具（含 jq/Python YAML/cmp/flock）→ 识别安装/恢复 → 同一十项 wizard → 确认后 Docker Engine/Compose/daemon/测试容器 → 持久目录/密钥/Compose → PostgreSQL/AnythingLLM/n8n/协议适配 → API Key/workspace/Prompt/知识对账 → workflow 导入/发布/实际 Code → 配置 revision 回读 → crispai → 本地/Provider/Crisp/公网/会话 facts。

普通文件来源主步骤：API 地址、隐藏 Key、模型数字、Website ID、隐藏 Identifier、隐藏 Token Key、公网接入、Prompt 路径、知识目录、脱敏确认。多行/多库是可选扩展，不伪称总共十次按键。默认客服/欢迎启用、人工按钮启用、1800 秒恢复、自动展开关闭；升级保留原值。

配置闭环为受限候选→校验→历史备份→原子提交→实际组件应用→读回→applied_revision。Provider 失败恢复时再次提高 revision，旧请求不能带着相同代次重新发送。普通业务开关不重启容器；Provider 变更需要按组件重建；Prompt/知识通过实际 API 应用。

## 6. 会话状态、计时与准确边界

状态以 SHA256(website_id + NUL + session_id) 隔离。持久 `mode/generation/resume_at/last_human_at/control_watermark/offers/jobs/outgoing` 与全局 revision 分开。待确认 offer 不等于 human；控制事件先持久化，再决定是否发送通知。

仅有效按钮确认与真人公开回复进入 human。自己的每类出站均有 automated/fingerprint 记录，回流先于 REST 响应也能识别；字段缺失时有界回查，失败只取消本次不确定出站，不捏造真人证据。内部 note、在线、正在输入、后台打开不是人工。

正数恢复从最近有效人工事件计算，访客及重复/旧事件不改变；0 永久。到期只回答新问题，不补历史、不发恢复通知。每 5 秒持久扫描，消息/状态/发送前也惰性校验；没有长模型锁。全局关闭保持控制接收，不修改所有会话为人工，重新启用不清空原截止时间。

真实本地已验证：A 展示但仍 AI、点击只暂停 A、B 正常；慢模型期间真人或总开关介入后迟到答案不发；第 6 秒追加人工把 10 秒截止移至至少第 16 秒；n8n 重启后永久状态与 offer 可继续；发送连接中断按 fingerprint 回查仅收到一次。远端已经收到的 POST 无法撤回，不能承诺跨系统绝对零竞态或严格 exactly-once。

## 7. Prompt、多知识库、欢迎与图片证据

D 通过 `/usr/local/bin/crispai` 在陌生 cwd 操作，Prompt 中文/空行/Emoji/特殊字符与真实 workspace SHA 相同。三个虚构命名库各自索引，中文改写问题 Top1 正确，初始 score 分别 0.543255、0.545880、0.528536；这是实际向量检索，不靠协议模型固定答案。旧默认库保留四种有效格式。

停用库从 workspace 新检索移除，其他库 location 不变；重新启用/重复同步不膨胀；单库重建不重建其他库。同名条目更新保持 ID，新事实可检索；删除一库后通过真实菜单迁移导入恢复其原文/索引，Prompt 与本机 .env hash 保持。

Chromium 152 的 7 组页面验证通过：加载展开、关闭展开仍欢迎、全局静默、欢迎关闭、打开事件欢迎、人工不展开/不欢迎、配置不可取不展开；实际连接 n8n 公共路由与 Hook。浏览器 Crisp SDK 是明确的协议 fixture，不等于真实 Crisp UI/站点验收。没有秘密进入页面，测试 TLS 仅 localhost 自签名证书的公钥 pin，不是公网证书验收。

图片以真实 PNG 字节协议 fixture 验证 Chat/Responses data image、当前会话历史及后续现有知识问答；拒绝非图片、过期/超大/受限网络，失败不转人工。真实第三方视觉能力与实际客户图片仍在外部待验证范围。
