# ai-support v1.0.0

首个正式源码版本，用于通过 Shell 部署 Crisp AI 自动客服。

## 主要内容

- Docker Compose 部署 n8n、AnythingLLM 与 PostgreSQL，运行数据集中保存在部署目录。
- 安装时检测 OpenAI Compatible Provider 的模型、Chat Completions、Responses 和视觉能力。
- 支持 Crisp Website Hook 与 Plugin Hook、连续 conversation 上下文、防重复回复、图片消息和欢迎菜单。
- AI 默认优先；仅 operator 主动公开回复或用户命中配置化人工关键词时关闭 AI。
- 支持配置化关键词、Prompt、多级菜单、标签、匿名知识命中统计和回答反馈。
- 支持 Markdown、TXT、PDF、DOCX 知识同步、备份恢复、版本快照、失败回滚和安全卸载。

## 安装

```bash
git clone https://github.com/statusX7/ai-support.git
cd ai-support
sudo ./install.sh
```

安装程序会要求部署方提供自己的 Provider 和 Crisp 配置，并在服务启动、AnythingLLM 初始化、workflow 发布及完整健康检查成功后写入 `ready` 状态。
