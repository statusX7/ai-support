# ai-support v1.0.1

本版本修复 v1.0.0 的快速初始化与依赖自动安装链路。

## 主要修复

- `sudo bash ./install.sh` 在无配置实例上直接进入十项中文向导。
- 安装器在首次使用前补齐运行工具，并在 Debian/Ubuntu 支持分支自动安装 Docker Engine、Compose 与 containerd、启动 daemon、运行测试容器。
- 自动完成 AnythingLLM Developer API Key、工作区、Prompt、知识索引及 n8n workflow 导入/发布。
- 支持裸域名受管 HTTPS 和现有 HTTPS 反向代理两种 Webhook 接入。
- 用 `local-ready` 与独立 fact 区分本地安装完成、Crisp 凭据、公网 Webhook 和真实会话状态。
- 管理工具改为十项中文分组，实际接通依赖修复、配置、知识、维护和数字确认卸载。
- 加固特殊字符配置、临时凭据清理、v1.0.0 升级自举及固定清单 Release 打包。
- 修复低速首次索引、n8n task runner、健康等待和回滚数据重绑问题；生产 Webhook 在发布后必须通过真实 Code node 烟雾检查。
- 修复数字二次确认完整清理在 `set -u` 下提前退出的问题，并验证不会删除其他 Docker 容器或宿主 Docker。

## 安装

下载本 Release 的 `ai-support-v1.0.1.tar.gz` 与 `SHA256SUMS`：

```bash
sha256sum --check SHA256SUMS
tar -xzf ai-support-v1.0.1.tar.gz
cd ai-support-v1.0.1
sudo bash ./install.sh
```

准备自己的 OpenAI Compatible API、Crisp Website 凭据，以及公网域名或现有 HTTPS Webhook 地址即可；无需手工安装 Docker、配置 PostgreSQL、AnythingLLM 或 n8n。

## 从 v1.0.0 升级

从本 Release 解压目录运行新版更新器：

```bash
sudo bash ./update.sh \
  --deploy-dir /opt/crisp-ai \
  --source-dir "$PWD" \
  --no-pull
```

不要使用已运行在旧进程中的 v1.0.0 管理菜单复制新版文件。

## 外部验收边界

本地空机引导、真实 Docker daemon、PostgreSQL、AnythingLLM、n8n、知识索引、workflow、重启、维护与发布包均按报告执行。若发布维护环境没有专用 Crisp 测试 Website、有效外部 Token 或可控制 DNS，则对应真实 Crisp conversation、公网投递和第三方模型能力会在报告中明确标记 `External Validation Pending`，不计为通过。

完整证据见 `docs/reports/v1.0.1-report.md`。
