# v1.3.1 发布说明

本版修复全新安装的受管 Caddy 预检阻断，并改善第三方中转模型的推理预算、可选参数兼容及容量诊断。安装 Token 输入按用户要求直接可见；请在私密终端操作，摘要和日志仍保护秘密。

- Caddy 使用非交互预检，不跳过真实配置验证，也不在没有合法候选时强制启动。
- 推理模型探针获得有限的可见输出预算；明确不支持 temperature 的中转仅在同候选剩余时间内作一次兼容重试。
- 上下文按接口手动配置和回读；65535 不是任何模型容量的保证。
- 实测兼容目标中转的 gpt-6.1-sol（Responses）、claude-sonnet-4-6 与 deepseek-v4-flash（Chat）。不宣称支持全部中转或原生 Anthropic 协议；上游仍采用非流式请求，SSE 为完成后缓冲包装。

已发布 v1.3.0 的 tag 和资产保持不变。发布只在全新安装、TARGET-A 同包验收及隐私门槛完成后进行；最终提交、归档摘要、实际安装与匿名下载结果由本版独立核验附件记录。详见[修复报告](../reports/v1.3.1-report.md)。
