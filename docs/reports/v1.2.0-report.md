## 5. 用户资料与限制

本轮唯一推荐安装命令（与 README、INSTALL、发布说明逐字一致）：

```bash
bash -c 'set -euo pipefail; u=https://raw.githubusercontent.com/statusX7/ai-support/main/get.sh; t=$(mktemp /tmp/crispai-get.XXXXXXXX); cleanup(){ r=$?; trap - EXIT; rm -f -- "$t"; exit "$r"; }; trap cleanup EXIT; f=; if [[ -s /etc/ssl/certs/ca-certificates.crt ]] && command -v curl >/dev/null 2>&1; then f=curl; elif [[ -s /etc/ssl/certs/ca-certificates.crt ]] && command -v wget >/dev/null 2>&1; then f=wget; else command -v apt-get >/dev/null 2>&1 || { printf "错误：当前系统无法自动安装安全下载工具。\n" >&2; exit 1; }; p=(); if (( EUID != 0 )); then command -v sudo >/dev/null 2>&1 || { printf "错误：需要 root 或 sudo 补齐安全下载工具。\n" >&2; exit 1; }; p=(sudo --); fi; "${p[@]}" env DEBIAN_FRONTEND=noninteractive apt-get -q -o APT::Color=0 -o Dpkg::Use-Pty=0 -o DPkg::Lock::Timeout=180 -o Acquire::Retries=3 -o Acquire::http::Timeout=30 -o Acquire::https::Timeout=30 update; "${p[@]}" env DEBIAN_FRONTEND=noninteractive apt-get -q -o APT::Color=0 -o Dpkg::Use-Pty=0 -o DPkg::Lock::Timeout=180 -o Acquire::Retries=3 -o Acquire::http::Timeout=30 -o Acquire::https::Timeout=30 install --yes --no-install-recommends ca-certificates curl; f=curl; fi; if [[ "$f" == curl ]]; then curl -q --fail --location --silent --show-error --max-redirs 5 --proto "=https" --proto-redir "=https" --tlsv1.2 --retry 3 --retry-delay 2 --connect-timeout 15 --max-time 300 --output "$t" "$u"; else wget --no-config --no-netrc --https-only --secure-protocol=TLSv1_2 --timeout=30 --tries=3 --output-document="$t" "$u"; fi; e=; while IFS= read -r l || [[ -n "$l" ]]; do e=$l; done < "$t"; [[ -s "$t" && "$e" == "# crispai-get-end" ]] && bash -n "$t" || { printf "错误：get.sh 下载不完整或语法无效。\n" >&2; exit 1; }; chmod 0700 "$t"; bash "$t"'
```

复用实际部署根，默认 `/opt/crisp-ai`，不强迁旧目录。Prompt 是 `config/prompt.md`，知识原文为 `knowledge/kb_*/sources/`；catalog、索引和 map 由程序管理。`config/materials-applied.json` 为最后有效运行投影，原文保存不等于已应用。秘密仍在受限 `.env`，不进入公共目录或无秘密业务包。

校验/应用链为：读取原文→严格候选校验/hash→保留上一有效资料→必要时 applying 暂阻普通回复→实际同步→回读→发布 applied。人工控制继续持久接收。失败不清全局/人工/offer，无法确认外部恢复时保持受阻并明确提示继续应用或恢复。

| 对象 | 实际源码边界与越界行为 |
| --- | --- |
| Prompt | configuration/wizard/materials：1～262144 UTF-8 字节，拒空白、无效编码和 NUL |
| 知识粘贴/单文档 | 粘贴最多 8 MiB；文件/直接应用 1 字节～50 MiB，MD/TXT/PDF/DOCX 预检，不静默截断 |
| 目录 | knowledge inventory：深度 16、扫描成员 20000、普通文件 10000；链接/控制路径拒绝，不支持格式不入库 |
| 库/文档数量 | 100 库、每库 10000 条；跨库同名不覆盖，单次目录内重名拒绝 |
| 配置/目录投影 | 每配置 1 MiB、catalog 512 MiB、运行投影/来源 map 16 MiB，不能绕过数量/单文件限制 |
| 业务迁移 | 压缩 128 MiB/展开 512 MiB/20000 成员，路径、链接、特殊文件、重复、schema/hash 均校验 |
| 模型/解析 | 文件字节不是模型 token 上限；固定组件与模型仍有资源/上下文限制，解析或上传不等于索引/正确回答 |

`人工客服` 是 4 个汉字、12 个 UTF-8 字节；1 KiB=1024 字节。具体常量、输入入口和阶段区别见 CONFIG，不把扫描 PDF 头通过解释成 OCR 能力。

## 6. 日志来源与安全边界

| 来源 | 位置/存储者 | 保留与处理 |
| --- | --- | --- |
| 生命周期 | logs/maintenance.jsonl 及受管轮转 | 白名单事件落盘；受管清理不接收任意删除路径 |
| doctor | 最后缓存、历史和诊断导出 | 限量结构化、脱敏，带检测时间和缓存标志 |
| 四组件/可选 Caddy | Docker json-file | 每服务 max-size/max-file；改变策略须重建并回读，不直接改 engine LogPath |
| n8n execution | PostgreSQL 内 n8n 官方记录 | 成功/错误正文不保存，官方 pruning；不删除活跃任务/WAL |
| runtime 业务记录 | data/runtime | 必要会话/offer/jobs/出站不是可清理日志，不纳入运维清理 |

## 8. TARGET-A 当前事实

原正式 `crispai` 在普通用户、sudo/root、新登录和陌生 cwd 可达；`crisp` 缺失是独立兼容入口问题。真正阻断客服的是受管反代 404、尚未登记的 Website Web Hooks，以及投递恢复后发现的 Crisp 出站字段拒绝；不是全部归咎命令拼写。

用户已完成 Web Hooks 登记和权限配置。本轮真实新访客消息被 Crisp 公网投递，实际模型答复返回原窗口；关键词仅展示 optional picker，取消后继续 AI，确认只暂停 A，B 仍正常。A 人工期访客追加消息不延时；只对验收 A 设短期限，真实调度恢复，原默认 1800 秒不变。重复、旧代次与自然过期卡更新不重新接管。B 图片处理及不带编号的后续指代正确，未跨会话。

未向普通客户发送验收内容，未伪装真人。目标机已从完整 v1.2.0 第三候选包同版安装并再次完成专用访客往返，生产流程实际刷新了单文件挂载。唯一自检 WARN 是受管 Caddy 没有容器 healthcheck（实际路由另已验证），SKIP 是默认不推理。正式同包核验仍待发布回执，因此此刻**不能声明目标机最终验收完成或可撤销临时账号**。

## 9. 公开安全与最小外部动作

本任务书及连接附录未入 Git。精确清单在受限环境检查字面值和常见编码，输出只含计数/位置；新增目标会话和附件引用也纳入清单。冻结前须复扫 index、可达历史、归档每成员、notes 和全部回执，通用秘密扫描独立执行。

本轮已匿名下载检查现有 4 个正式 Release 的全部说明与 9 个资产，共检查 234 个说明/归档成员；截至候选4提交，全部可达历史含 606 个去重文件对象，精确秘密与常见编码命中为 0。现有远端只有 main，Actions 历史运行/制品、Issues、PR 均为 0；不是只扫描最新 main。后续报告提交与最终附件仍独立复扫。

用户不需要再登记已完成的 Hook；真实客服后台公开回复仅在专用验收会话协调。其他使用者仍须从自己的账户取得有效 Provider/Crisp 及 DNS/TLS，按 CRISP 指南登记准确生产地址和事件。没有外部权限的项目明确标注，不能用 External Validation Pending 豁免已能复现的软件故障。
