## 8. External Validation Pending

以下项目没有在本次发布环境执行，均不计为通过：

- 专用 Crisp Website、Website Token 或 Plugin Token 的真实 REST 权限。
- 公网 HTTPS Website Hook 与 Plugin Hook 的真实投递、URL Secret 和 HMAC 签名。
- Crisp → n8n → AnythingLLM → Provider → Crisp 的真实文本回复。
- 真实 Crisp conversation 上下文、防重复、operator 关闭 AI、用户明确转人工、标签权限降级和欢迎语。
- Crisp 图片 URL 到视觉 Provider 再回写 Crisp 的完整链路。
- 使用部署方真实 Provider Key 和生产知识文件的实例验收。
- v1.0.0 当前源码在新服务器上的完整首次安装 `ready`、成功更新及完整健康检查。

现有外部 E2E 脚本覆盖主要消息链路，但 Website/Plugin 两轮配置、部分鉴权负向场景和欢迎语仍需按 `docs/TESTING.md` 分别验收，不能用单轮脚本结果替代。

## 9. 部署方式

```bash
git clone https://github.com/statusX7/ai-support.git
cd ai-support
sudo ./install.sh
```

安装程序依次执行环境与 Docker daemon 检查、部署目录和权限初始化、Provider 模型与能力检测、Crisp 配置、容器启动、AnythingLLM 初始化、Prompt 同步、workflow 发布和完整健康检查。只有全部实例检查成功才写入 `state=ready`。

安装后运行：

```bash
sudo /opt/crisp-ai/manage.sh
```

## 10. 已知限制与风险

- Crisp、公网 Webhook 和部署方 API 凭据属于实例配置，本源码 release 不包含这些值；没有配置时安装不会错误写成 `ready`。
- v1.0.0 当前测试没有重新启动真实 Docker daemon；容器级证据继承自生产路径未改变的 v0.8.2 真实验收，当前只重新执行了 Compose 解析、静态与桩测试。
- AnythingLLM 版本快照可能包含知识或会话运行数据，只能保存在受限部署目录，禁止上传。
