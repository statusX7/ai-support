# v1.3.0 发布说明

> 当前为冻结前说明。只有 TARGET-A 通过同一正式候选包、公开 Release 实际创建并匿名回下载核验后，才可将本版描述为已发布。

v1.3.0 聚焦两个 P0：符合自动应答条件的消息必须保留可追踪责任，不能因 Hook 漏投、队列/许可、配置换代、发送未知或补偿预算静默消失；当前有效知识已经明确回答的问题，最终模型输入和访客答案必须采用该事实，不能用固定空泛追问替代。

本版保留 v1.2.1 的评价邀请停用、1 主最多 20 备、中文菜单、中性客服显示、真人公开回复立即暂停当前会话及可配置的人工恢复。消息故障与知识正确性分别记录：投递成功不等于回答正确；只有确实缺少必要业务信息时才提出具体澄清，检索或模型故障不得转换成访客可见的空泛追问。

发布流程由 `config/release-policy.json` 硬性限制为唯一 v1.3.0。所有产品测试、冻结包构建验收和真实业务往返均在 TARGET-A 执行；同包门禁通过前，发布入口拒绝 push、tag、draft 和 Release。

唯一推荐安装命令沿用 README 与安装文档中的公开入口。正式发布前它仍安装当前 Latest，不会下载未发布候选。
